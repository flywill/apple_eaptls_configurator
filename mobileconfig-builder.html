The name on the server's own certificate. It is in neither the CA nor the .p12, so read it from the server with

The CN and the subjectAltName normally carry the same name. Where they differ, use the subjectAltName: iOS 13 and later match on that and ignore the CN.

3 · Result







  If you have a .crt and a .key instead of a .p12,
  combine them first. A browser cannot build a PKCS#12 bundle, so this step
  needs openssl:
  
openssl pkcs12 -export \
  -in alice.crt -inkey alice.key -certfile ca.pem \
  -name alice -out alice.p12

  Treat the finished profile as a private key. It contains the user's key
  and the password that unlocks it. Transfer it, install it, then delete your copy.
